The funniest honest error message an appliance could show — a blender reports, flatly, what it did to the spoon. One line, 88 characters.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```

Writes one line to `out/entry.txt` (88 characters, no trailing newline):

> I blended the smoothie. I also blended the spoon. The spoon is part of the smoothie now.
